Manuscript pre-review, in one API call

Submit a manuscript and get a summary, keywords, readability metrics, a plagiarism check, a citation report and reviewer suggestions.

Summaries & keywords

A local summarisation model (DistilBART) and YAKE keyword extraction, with no data leaving the server.

Readability

Flesch reading ease, Flesch–Kincaid grade level and the Coleman–Liau index per manuscript.

Plagiarism detection

MinHash fingerprints compare a manuscript against the documents of the same tenant.

Citation analysis

Detects the citation style, flags malformed references and reports orphan citations.

Reviewer matching

Keyword and semantic matching with conflict-of-interest checks based on the affiliation.

Multi-language

Automatic language detection with a per-language spaCy pipeline for entity extraction.

Quick start

Register an account, then submit a manuscript. The API answers with a task id that you poll for the result. 

curl -X POST http://localhost:8000/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"username": "author", "email": "author@example.com", "password": "Password1!"}'

curl -X POST http://localhost:8000/api/v1/auth/login \
  -d 'username=author&password=Password1!'

curl -X POST http://localhost:8000/api/v1/analysis/pre-review \
  -H 'Authorization: Bearer ' \
  -F 'manuscript_text=Your manuscript text here...'

curl http://localhost:8000/api/v1/analysis/status/ \
  -H 'Authorization: Bearer '
